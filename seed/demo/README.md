# Demo Seed

The demo seed is deterministic sample data used to initialize each isolated anonymous demo workspace.

It must:

- contain no real personal or health data
- use the same schema and APIs as registered workspaces
- be resettable
- be versioned
- include products, schedules, and batches sufficient to demonstrate Today and Cabinet

It must not create one shared writable demo user.

Current Phase 2 seed: D3, magnesium, and fish oil with relative dates and no
historical intake. Intake-history examples are still pending and must use the
same allocation/event transaction as ordinary demo activity.
