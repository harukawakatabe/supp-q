# 完整产品目标范围

> 这里不用“MVP 范围”命名，因为 `mvp/` 是完整产品思想的历史实现。以下是目标范围，不是下一次发布必须一次完成的承诺。

## 做：完整目标能力

### 1. 采集、识别与确认

- 正面、成分表、有效期三类照片；相册、拍摄、重试、替换和手工输入可混用。
- 中英文标签识别与英译中；原文和中文并存。
- 结构化提取产品名、品牌、成分、每份剂量、建议用法、总数量、有效期、警示等字段。
- 每张图有独立状态和错误恢复；用户只需进行一次完整确认。
- 展示证据、置信度、来源和低置信提示；所有关键字段可编辑。
- 识别失败、超时或供应商不可用时，手工建档仍能走完整闭环。

### 2. 药剂柜与产品资料

- 在用、暂停、耗尽等状态；搜索、筛选、分类与详情。
- 产品基础资料、图片、成分、建议用法、计划、批次和库存的查看与编辑。
- 新增批次、调整库存、删除/停用产品，并处理其对今日任务和历史记录的影响。
- 产品笔记、使用原因、个人反应等上下文沉淀。

### 3. 计划、今日与提醒

- 每日、每周和间隔天周期的组合计划，并保留历史版本。
- 早晨、中午、下午、晚上等时间段，以及随餐/空腹等执行提示。
- 今日按时间段展示应服项目，支持前后日期切换、补录和从药剂柜临时选择。
- 计划总览、未来周期时间线和单品日历。
- 全局与单品提醒、低库存提醒、临期提醒；具体系统推送渠道为 `OPEN`。

### 4. 记录、库存与成本

- 计划服用、历史补录、临时服用三类记录。
- 记录与库存一次性更新；幂等防重复；撤销时精确恢复原批次分配。
- 多批次 FEFO 消耗、预计耗尽日、最晚启用日、缺货和临期风险。
- 补货/批次成本、单次成本、累计消耗成本和库存价值账本。

### 5. 成分日历与数据导出

- 产品成分、同义名归一、质量单位换算与可解释的 IU 处理。
- 按日聚合实际摄入量，展示产品/手工记录来源。
- 成分日历、成分详情、手工成分摄入和历史修改。
- CSV 预设及自定义导出，导出定义必须和界面统计一致。

### 6. AI、笔记与健康资料

- 产品级与成分级对话，输入只来自用户已确认的数据和明确的参考资料。
- AI 结果可以保存为笔记，保留来源、时间和上下文。
- 健康资料由用户维护，并明确控制哪些内容进入 AI 上下文。
- 计划、库存、单位换算、风险阈值等确定性结果不能由 LLM 决定。
- 处方药、剂量和相互作用边界为 `OPEN`，确认前不得扩张。

### 7. 身份、隐私与数据控制

- 邀请注册、登录、会话和工作区隔离；Demo 与真实账户数据隔离。
- 多设备使用同一服务端权威数据，避免 Web 版整包状态覆盖。
- 原图私有存储与授权访问；数据可导出；账户可删除且完成级联清理。
- 管理邀请、外部供应商配置与最小必要的管理操作。

### 8. 工程可靠性

- 异步识别任务、重试、超时、租约与 Worker 心跳。
- 明确区分真实识别、降级、人工输入和 Demo/Mock。
- 固定精度或等价的可验证数值语义，避免库存和剂量浮点漂移。
- API 契约、迁移、备份恢复、监控、指标、错误码与部署手册。

## 交付顺序建议

以下仅为 `DEFERRED-ORDER`，不是范围删减：

1. **闭环补齐**：多成分确认、完整产品编辑、临时服用、计划/今日一致性。
2. **日常可用**：提醒配置、计划总览、批次/成本界面、完整记录筛选。
3. **理解与沉淀**：成分日历、手工摄入、导出、笔记、健康资料。
4. **受控智能**：产品/成分 AI，在安全边界与评测集明确后接入。
5. **多端扩展**：小程序上传和通知渠道；不得在实现前宣称可用。

## 不做：产品边界

这些边界来自现有 PRD；如需改变必须重新定型：

- 不做诊断、处方开具或自动替用户决定剂量。
- 不把 AI 文本作为医学事实、库存事实或计划规则的权威来源。
- 不自动判断复杂药物相互作用或给出疾病治疗方案。
- 不做电商购买闭环、社区内容流或医生工作台。
- 不在没有明确换算因子的情况下强行合并不可兼容单位。
- 不让识别失败阻断手工建档，不让撤销变成删除历史痕迹的黑盒操作。

## 成功指标

当前没有真实基线数据。下面是 `DRAFT / UNMEASURED` 指标框架，不能写成已达成结果。

| 指标 | 定义 | 初始目标建议 | 数据来源 |
| --- | --- | --- | --- |
| 建档完成率 | 开始新增后，在 24 小时内确认产品且生成可执行计划的用户占比 | ≥ 70% | 前端事件 + 服务端产品/计划记录 |
| 识别辅助成功率 | 上传成功的识别集合中，无需完全手工重建即可确认的占比 | ≥ 60% | 识别任务、确认差异与来源标签 |
| 今日任务完成率 | 到期计划任务中，当日或允许补录窗口内完成的占比 | 先测基线，再定目标 | 计划快照 + intake 记录 |
| 库存账本一致率 | 回放 intake、undo、adjustment 后计算库存与存储库存一致的对象占比 | 100% | 服务端审计作业 |
| 撤销正确率 | 撤销后原批次分配、库存和记录状态全部精确恢复的成功率 | 100% | 事务日志 + 自动化测试 |
| 7 日留存/活跃 | 新建首个产品后第 7 天仍有查看或记录行为的用户占比 | ≥ 25% 仅作验证起点 | 匿名化产品事件 |
| 关键字段修正率 | 识别后产品名、成分、剂量、数量、日期等字段被修改的比例 | 监测下降趋势，不先设绝对值 | 识别结果与确认版本差异 |
| 数据控制完成率 | 导出、账户删除等操作按契约成功完成的比例 | 100% | 后端作业与审计日志 |
